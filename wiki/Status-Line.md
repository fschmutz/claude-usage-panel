# Claude Code status line

The Node status line was replaced by the [[Footer]]: the `usage-footer` plugin
draws the line under the Claude Code prompt, with the gauges flush right.

`./install.sh statusline` still works and installs the footer; `./install.sh
update` migrates a machine that still has the old status line. See
[[Footer#coming-from-the-status-line|Coming from the status line]].
